# Random Movie

Простое Android-приложение на Kotlin и Jetpack Compose, которое предлагает случайный фильм из списка.

## Возможности

- фильмы хранятся в `strings.xml` как `string-array`;
- фильмы не повторяются в пределах одного цикла;
- после окончания списка выводится сообщение;
- кнопка сброса начинает новый цикл;
- две локализации: русская и английская.

## Запуск

Откройте проект в Android Studio и запустите конфигурацию `app` на устройстве или эмуляторе с Android 7.0 (API 24) или новее.
